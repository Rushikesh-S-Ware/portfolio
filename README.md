## 🚀 Overview

This is my **personal portfolio website**, showcasing my projects, technical skills, and résumé.  
It’s designed to be minimal, responsive, and built using **React.js** and **Bootstrap**.

---

## 🛠 Built With

- React.js  
- React-Bootstrap  
- CSS3  
- JavaScript  
- GitHub Pages / Vercel  
- VS Code

---

## ✨ Features

- 📖 **Multi-Page Layout** (Home, About, Projects, Resume)  
- 🎨 **Custom Theme** with React-Bootstrap and CSS  
- 📱 **Fully Responsive** on all devices  
- ⚙️ **GitHub Integration** (live projects and repositories)
